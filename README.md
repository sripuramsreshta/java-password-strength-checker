
# Java Password Strength Checker

## Project Goal
This project is a Java program that checks how strong a password is. The goal is to help users understand whether their passwords are secure and what makes a password stronger.

## MVP Features
- Allow users to enter a password.
- Check if the password is at least 8 characters long.
- Check if the password contains numbers.
- Check if the password contains special characters.
- Give the password a strength rating of Weak, Medium, or Strong.

## Future Plans
- Add suggestions for improving weak passwords.
- Create a graphical user interface.
- Add a random password generator.

## Tech Stack
- Java
- Scanner for user input
- Built-in Java String methods
- VS Code for development
- Git and GitHub for version control

The program will run locally and won't require a database or external APIs.
